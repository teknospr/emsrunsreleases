# EMSRuns — desktop app downloads

EMSRuns for **Windows, Mac and Linux**. Download the latest version from [Releases](https://github.com/teknospr/emsrunsreleases/releases/latest).

| Computer | File |
|---|---|
| Windows 10 / 11 | `EMSRuns-<version>-win-x64.exe` |
| Mac with Apple chip (M1 or newer) | `EMSRuns-<version>-mac-arm64.dmg` |
| Mac with Intel | `EMSRuns-<version>-mac-x64.dmg` |
| Linux (any) | `.AppImage` |
| Ubuntu / Debian | `.deb` |

The app opens EMSRuns. If your company has its own EMSRuns server, use **Server → Change server** (or **Cambiar servidor** on the sign-in page) and scan the QR code from your administrator, or type the address.

**First time opening it**
- **Windows:** if "Windows protected your PC" appears, choose **More info → Run anyway**.
- **Mac:** right-click (or Control-click) EMSRuns in Applications → **Open** → **Open**.
- **Linux AppImage:** make it executable (right-click → Properties → Allow executing, or `chmod +x`), then open it.

Windows and the AppImage update themselves. On Mac and .deb the app tells you when a new version is available and opens this page.
